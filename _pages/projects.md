<h2 id="volumetric-video" class="proj">Capturing volumetric video <span class="proj-year">2017</span></h2>
<p class="proj-meta">Side project · <a href="https://github.com/alex-petrenko/4dvideo">github.com/alex-petrenko/4dvideo</a></p>

"4D video" grabber and player for Intel RealSense and Google Tango.
The player is based on modified Guibas-Stolfi triangulation algorithm and can generate 3D mesh in real time (300fps on PC, 100fps on Android).
With this software I captured [a lot](https://skfb.ly/6s77X) of cool 4D clips:

<h2 id="microtbs" class="proj">RL agents for a game "MicroTbs" <span class="proj-year">2017</span></h2>
<p class="proj-meta">Side project · <a href="https://github.com/alex-petrenko/rl-experiments">github.com/alex-petrenko/rl-experiments</a></p>

An OpenAI Gym-compatible 2D environment and some RL algorithms trained in it: Double DQN, A2C, etc.
Inspired by an old game [Heroes of Might and Magic III](/assets/img/projects/homm3.jpg), which is quite challenging for contemporary AI.
I designed this environment to resemble some of the features of the original game: scouting, different terrain, picking up resources, etc.
